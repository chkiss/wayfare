This is a private instance of wayfare, a tool that reads travel booking documents — boarding passes, confirmation emails, hotel reservations — and turns them into calendar events, after checking that what it read is actually possible.

What it does

Text is extracted from an uploaded document on this server. Airport codes, timezones and distances are checked against an offline database, so an impossible departure time or a hotel booked before the flight lands is caught rather than written to a calendar. Events are created on a quarantine calendar first; only those passing every check move to the real one, and every write can be undone.

Who can use it

Only the person holding this instance's access token. There is no public sign-up, and it acts on one Google account — the owner's.

Privacy · Terms

{% elif page == "privacy" %}
The short version

This is a single-user, self-hosted instance. Your data stays on this server and is shared with nobody. There is no analytics, no advertising, no tracking, and nothing is sold or transferred to anyone.

Google user data this app accesses

With your permission it uses the Google Calendar API to:

  • create calendar events from the booking documents you give it;
  • move an event from the quarantine calendar to your main calendar once you approve it;
  • read events in the days surrounding a booking, solely to warn you that a booking may already be on your calendar.

It does not read your calendar for any other purpose, and it never transmits your calendar data off this server.

What is stored, and where
  • The Google credential. A refresh token, stored on this server with owner-only file permissions, so the app can act on your calendar without asking you to sign in again.
  • Uploaded documents. Held in a temporary directory only while being read, then deleted. The extracted text is not kept; a one-way hash of it is, so a document submitted twice can be recognised.
  • A record of each submission. What was extracted, which checks passed, and the identifiers of the events created — kept so you can review and undo them.
Third parties

When a document has no barcode and no embedded text, the extracted text may be sent to the language model provider configured by the instance owner, to work out which parts of it describe a flight. No image, no calendar data and no credential is ever sent. If no model is configured, this does not happen at all.

Withdrawing access

Revoke this app at any time from your Google account's third-party access page. To erase what is held here, delete the instance's state and secrets directories on the server, or ask the owner to.
